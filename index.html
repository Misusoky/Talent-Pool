🎯 AI人才库系统

波克城市 - HR实习生岗位能力测试项目

📋 项目说明

这是一个基于Flask + Claude AI的智能人才库管理系统，完整演示了一个现代化的HR解决方案。

📥 简历导入

支持PDF简历拖拽导入，自动提取邮箱、电话等关键信息

🤖 AI分析

使用Claude AI智能解析简历，提取岗位信息和职业发展分析

👥 人才库管理

完整的人才信息管理系统，支持查询和编辑

📢 岗位管理

创建和管理招聘岗位，定义岗位要求

🎯 智能匹配

基于AI的人岗匹配，自动推荐最适合的候选人

📊 匹配历史

记录所有匹配结果，支持追踪和分析

🛠 技术栈

Flask Python Claude AI API SQLite HTML5 CSS3 JavaScript PyPDF2

📚 核心功能演示

1. 人才库

查看导入的所有候选人信息

2. 招聘岗位

创建和管理招聘岗位需求

3. 智能匹配

AI自动匹配人岗适配度

4. 匹配历史

查看历史匹配结果记录
